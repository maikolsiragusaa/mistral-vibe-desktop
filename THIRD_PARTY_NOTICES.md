## Frozen Python backend

The installer places the official `mistral-vibe==2.26.1` app server under `resources/backend/vibe-app-server`. Its Python dependency and PyInstaller license files, the manifest, and the Python PSF license are copied by `scripts/build-backend.ps1` into `resources/backend/vibe-app-server/licenses/`. Read `THIRD_PARTY_NOTICES.generated.md` and `manifest.json` there for the exact frozen dependency versions and licenses. The build disables and excludes the optional `textual-speedups` Textual TUI geometry accelerator because this stdio app-server has no TUI; the package is not present in the frozen output.
